# Taskrail v0.8.8

相较于 v0.8.7：

- 新增“段首缩进”阅读设置：正文段落默认缩进两字符，也可关闭并随字号缩放；列表标记列同步与正文首行缩进对齐。
- 修复中文括号紧邻删除线时删除线无法生效的问题。
- 修复切换项目后阅读位置持续下移的问题。
- 修正输入法在新位置提交闭引号的方向。
- 重绘默认项目图标，使轮廓与留白更清晰。

0.8.8 沿用 0.8.7 的应用标识，可覆盖升级。Windows 下载 `Taskrail_0.8.8_x64-setup.exe` 安装，Android 下载 `Taskrail-0.8.8-arm64.apk` 安装。

局域网同步协议未变，兼容范围与 v0.8.7 相同。含画布图片的文档需要两端都运行 0.8.0 或更新版本。与 v0.7.2 及更早版本不兼容，两端需一起升级。

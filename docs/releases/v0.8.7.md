# Taskrail v0.8.7

相较于 v0.8.6：

- 支持自定义左侧边栏项目图标，可选择表情或图标，也可恢复默认图标。
- 修复电脑和手机解除配对后另一端未及时更新的问题，重新配对后保留原有同步选择。
- 改进手机导航手势，在屏幕中心区域滑动可打开或关闭导航，快速滑动正文时不再意外唤起光标。
- 修复部分主题下编辑器光标颜色不明显的问题。
- 修复子任务操作和完成组摘要后出现多余空行的问题。

0.8.7 沿用 0.8.6 的应用标识，可覆盖升级。Windows 下载 `Taskrail_0.8.7_x64-setup.exe` 安装，Android 下载 `Taskrail-0.8.7-arm64.apk` 安装。

局域网同步兼容范围与 v0.8.6 相同。含画布图片的文档需要两端都运行 0.8.0 或更新版本。与 v0.7.2 及更早版本不兼容，两端需一起升级。

# 任务板的已结束任务

状态：有效

范围：[任务板筛选与任务生命周期](../../features/bounty-board.md#f-bnt-002-任务板筛选与任务生命周期)。

任务板首页用于查看仍需跟进的任务。「未结束」与「已结束」定义任务范围。右侧的分段按钮筛选当前视图内的状态，因此「全部」的含义由「未结束」限定。两个视图用相同的卡片布局，便于通过同一个位置打开详情。

取消任务会保留任务记录。管理员在详情抽屉确认永久删除。若后续任务仍依赖该任务，服务保留前置记录和依赖，避免后续任务提前开放接取。

转为草稿复用原任务标识，后续任务仍指向同一条前置任务。服务结束上一轮接取和协作，保留评论与事件历史。管理员可修改草稿，再由发布开启下一轮接取。

# 开发阶段的兼容边界

状态：有效

悬赏抢单统一通过注册 Agent 的正式入口完成。仓储和内存服务不提供绕过身份、准入与仲裁回避的抢单入口。同一写事务内的可接取状态只校验一次。评级和事故记录要求执行者存在于名录，缺失身份不视为成功结算；停用与吊销不免除已有租约的结算责任。

应用配置以 `locale`、`contentWidth`、`sidebarOpen` 为规范字段。旧别名与布尔缩进只在配置加载边界转换，运行时和保存结果只使用规范字段。

发布资源统一要求 Windows 安装包、更新签名、同版本 Android arm64 APK、更新清单和 SHA256SUMS。发布流程不为早期仅包含 Windows 安装包的版本保留单独规则。

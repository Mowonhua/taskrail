# 任务创建者身份

状态：有效

范围：[任务板筛选与任务生命周期](../../features/bounty-board.md#f-bnt-002-任务板筛选与任务生命周期)。

任务详情显示创建任务时的账户或 Agent。管理员凭证授权创建任务，用户会话确定实际创建账户。服务在创建任务时保存账户 ID，读取详情时读取账户的当前名称和头像。账户改名后，既有任务的详情也能显示新名称。

服务将账户关联保存在独立表，已有数据库可在初始化时补建该表。旧任务的 `created_by` 可由客户端传入，无法证明创建者身份，因此缺少账户或 Agent 关联的任务显示「未知创建者」。[任务接口](../../src-tauri/src/server/README.md)
